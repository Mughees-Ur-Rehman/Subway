# Subway Menu Directory (Independent Guide)

A high-performance, responsive web application offering a searchable directory for Subway Footlong subs, 6-inch sandwiches, wraps, salads, fresh cookies, and drinks alongside calorie and pricing details.

## Deployment Instructions
1. Save all files maintaining the directory structure.
2. Replace `https://YOUR-DOMAIN.com/` in `index.html`, `sitemap.xml`, and `robots.txt` with your live domain link (e.g., Vercel / Netlify URL).
3. Ensure `sitemap.xml` and `robots.txt` are positioned in your project root or `public/` directory depending on your deployment host.
